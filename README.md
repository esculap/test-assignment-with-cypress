# Test Automation Framework

This repository contains a test automation framework for a demo website, built using Cypress and JavaScript.

## Installation

Make sure you have [Node.js](nodejs.org) installed in you system.

Unzip the repository and run the following command to install the necessary dependencies:

```
npm install
```

## Usage

Run the tests in headless mode use the following command:

```
npx cypress run
```

To run tests in browser visible mode please use the next command:

```
npx cypress open
```

## Project Structure

The project structure is organized as follows:

- pages - contains the page object files that define the UI elements and interactions for each page;
- tests - contains the test files;
- fixtures - contains files for test purposes.
